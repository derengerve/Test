# Recyclage NP2900 Philips - Guide Complet

Ce projet fournit un guide complet et des outils pour recycler votre appareil de streaming NP2900 de Philips. Donnez une seconde vie à votre appareil avec différentes méthodes de recyclage.

## 📁 Contenu du Projet

- **`guide_recyclage_np2900.md`** - Guide détaillé de recyclage
- **`np2900_recycling_tools.sh`** - Script d'outils automatisés
- **`projets_recyclage.json`** - Configuration des projets de recyclage
- **`README.md`** - Ce fichier

## 🚀 Démarrage Rapide

### 1. Vérifier votre système
```bash
./np2900_recycling_tools.sh --check-system
```

### 2. Sauvegarder vos données
```bash
./np2900_recycling_tools.sh --backup-data
```

### 3. Choisir un projet de recyclage
Consultez le fichier `projets_recyclage.json` pour voir les options disponibles.

## 🔧 Méthodes de Recyclage

### Méthode 1: Patch Firmware
- Mise à jour du firmware officiel

### Méthode 2: Upgrade Matériel
- Remplacement de composants

### Méthode 3: Modification Logicielle
- Installation d'OS alternatifs

### Méthode 4: Recyclage Créatif
- Serveur NAS domestique
- Console de rétrogaming
- Centre de contrôle domotique
- Serveur web local
- Station météo connectée

## 🛠️ Outils Disponibles

Le script `np2900_recycling_tools.sh` offre plusieurs fonctionnalités :

```bash
# Vérifier le système
./np2900_recycling_tools.sh --check-system

# Sauvegarder les données
./np2900_recycling_tools.sh --backup-data

# Préparer une clé USB pour firmware
./np2900_recycling_tools.sh --prepare-usb

# Tester la connectivité réseau
./np2900_recycling_tools.sh --test-network

# Nettoyer le système
./np2900_recycling_tools.sh --clean-system

# Installer des applications utiles
./np2900_recycling_tools.sh --install-apps
```
