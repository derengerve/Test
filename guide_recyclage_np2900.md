# Guide de Recyclage - Appareil de Streaming NP2900 Philips

## Vue d'ensemble
Le NP2900 est un appareil de streaming multimedia de Philips qui peut être recyclé et réutilisé de plusieurs façons. Ce guide présente différentes méthodes pour donner une seconde vie à votre appareil.

## ⚠️ Avertissements de sécurité
- **Débranchez toujours l'appareil** avant toute manipulation
- **Utilisez un équipement antistatique** pour éviter les dommages
- **Sauvegardez vos données** avant toute modification
- **Vérifiez la garantie** avant d'ouvrir l'appareil

## Méthode 1: Recyclage par Patch Firmware

### Étape 1: Diagnostic initial
```bash
# Vérifier la version actuelle du firmware
Menu → Paramètres → Système → Informations système
```

### Étape 2: Téléchargement du firmware
1. Visiter le site officiel Philips
2. Rechercher "NP2900 firmware"
3. Télécharger la version la plus récente
4. Vérifier la compatibilité avec votre modèle

### Étape 3: Installation du patch
1. Copier le fichier .bin sur une clé USB formatée en FAT32
2. Insérer la clé dans l'appareil
3. Aller dans Menu → Paramètres → Système → Mise à jour
4. Suivre les instructions à l'écran
5. **Ne pas éteindre** pendant la mise à jour

### Étape 4: Réinitialisation
1. Menu → Paramètres → Système → Réinitialisation
2. Choisir "Réinitialisation complète"
3. Confirmer l'action
4. Attendre le redémarrage

## Méthode 2: Recyclage par Upgrade Matériel

### Composants remplaçables
- **RAM**: Mise à jour vers une capacité supérieure
- **Stockage**: Remplacement par un SSD plus rapide
- **Connecteurs**: Amélioration des ports USB/HDMI
- **Refroidissement**: Ajout de ventilateurs ou dissipateurs

### Outils nécessaires
- Tournevis cruciforme
- Pince à épiler
- Mat anti-statique
- Composants de remplacement

### Procédure d'ouverture
1. Retirer les vis de fixation
2. Ouvrir délicatement le boîtier
3. Identifier les composants à remplacer
4. Documenter les connexions avant démontage

## Dépannage Commun

### Problème: Appareil ne démarre pas
**Solutions:**
- Vérifier l'alimentation électrique
- Tester avec un autre câble d'alimentation
- Réinitialiser via le bouton reset
- Vérifier les connexions internes

### Problème: Pas de signal vidéo
**Solutions:**
- Tester différents câbles HDMI
- Vérifier les paramètres de résolution
- Réinitialiser les paramètres d'affichage
- Tester sur un autre écran

### Problème: Connexion réseau instable
**Solutions:**
- Vérifier la configuration WiFi
- Tester la connexion filaire
- Redémarrer le routeur
- Mettre à jour les pilotes réseau
